# 小阿尔卡纳 · 三张牌

纯静态塔罗抽牌网页：选择主题，随机抽取三张小阿尔卡纳，点击翻牌查看正逆位和主题相关解读。

## 本地预览

直接双击打开 `index.html` 即可，无需安装依赖。

## 部署

1. 把整个 `tarot-minor` 文件夹推送到 GitHub 仓库。
2. 在 Vercel 中导入该仓库。
3. 框架选择 Static / 无框架，构建命令留空，输出目录保持根目录。
